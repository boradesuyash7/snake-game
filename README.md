# Snake

A small desktop Snake game built with Python and Pygame.

## Run on Windows

Create and activate the project virtual environment in PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Use the arrow keys or WASD to steer. Press Space or Enter to start, `P` to pause, `R` to restart, and Escape to quit. Your best score is saved next to `main.py`.
